# SHRINEVA

Website for **SHRINEVA**, a commercial building (open stilt + three floors) at D-15, Bada Lalpur, Chandmari, Varanasi.

The Angular project is in [`shrineva/`](shrineva/). Build, deploy, domain-switch, form-activation and editing notes are in [`shrineva/README.md`](shrineva/README.md).

```bash
cd shrineva
npm install        # Node 18.x
npm run build      # output: shrineva/dist/shrineva
```

Public facts (areas, contact, address, domain) live in one file: `shrineva/src/app/config/property.config.ts`.
